## Exercise labelling

Every exercise cell is labelled, and the labelling is pedagogical rather than
decorative.

```python
# [TRY WITHOUT AI] ──────────────────────────────────────────────
# Attempt this yourself first.

# [USE AI] ──────────────────────────────────────────────────────
# Use an assistant here. Prompting is part of the skill.
```

The point is not that AI is forbidden. The point is that you should know which
muscle each exercise is training, and some of them you cannot outsource.
